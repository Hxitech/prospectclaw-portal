What You Can Finish

不是又一个聊天窗口，而是 Agent 的本地控制台

先把模型、Agent、工具和知识库管起来，再按场景运行研究、文档、SOP 或行业模块。

Deep Research

把开放问题拆成多 Agent 研究任务

输入一个研究目标，Privix 会把问题拆解给多个 Scientist Agent 并行处理，沉淀证据、结论和结构化报告。适合竞品分析、市场测算、技术选型、文档审阅等通用研究场景。

问题拆解 并行研究 证据汇总 报告导出
Multi-Agent Workflow

让多个 Agent 按任务链协作出结果

把研究、文档审阅、竞品监控、流程复盘这类复杂任务拆成 DAG 任务链，多个 Agent 按波次执行，最后汇总为一份可追踪的结果。你可以改角色、改依赖，也可以直接用内置模板。

DAG 任务链 多 Agent 接力 模板启动 结果汇总
Agent & Model Control

统一管理模型、工具和本地 Agent

不用在多个工具里来回配置。Privix 自动检测 Claude Code、Codex、Gemini、Qwen 等 CLI Agent，统一管理 23 家 LLM Provider 和 MCP 工具，让团队把配置留在本机。

CLI Agent 模型 Provider MCP 工具 本地配置
Claw Doctor

出问题时，先让内置助手帮你定位

模型、Gateway、Agent、Skills 哪一层坏了，不用靠猜。Claw Doctor 会检查环境、读取日志、诊断连接问题，并把修复动作写入本地审计记录。

环境检查 日志分析 连接诊断 审计留痕
Local Agent Runtime

底层引擎可切换，配置互不污染

OpenClaw 负责多 Agent 编排与工具链，Hermes 负责流式对话和 Python 生态集成。两套引擎可以按场景切换，配置、服务和日志路径彼此隔离。

OpenClaw Hermes 隔离配置 本地日志
Why Local

敏感研究资料，不该先上传到别人的云

Privix 把文档、会话、模型密钥和审计日志都留在本地。只有你主动调用模型时，才从本机直连自己配置的 Provider。

🔒

文件和会话留在本机

研究材料、项目记录、会话和 Agent 配置全部存储在本机 SQLite 文件中，没有强制同步和云端副本。

🔑

API Key 不交给 Privix

模型密钥加密存储在本地 keychain。Privix 不托管密钥、不代理请求，模型调用直接发往你配置的 Provider。

✈

无网也能查资料

不调用模型时，仍可浏览本地档案、编辑项目、维护 SOP 和整理知识库。网络只是模型调用所需，不是数据入口。

📄

关键动作可追踪

Agent 调用、模型请求和配置修改都写入本地日志，方便团队复盘、内审和问题定位。

Getting Started

先跑通一条真实工作流

如果你只是想知道 Privix 到底能干什么，先从本地 Agent 配置开始；行业模块可以之后再看。

📈

10 分钟体验 Invest 模块

从线索、公司资料到材料归档和审批，快速了解行业模块如何接入同一个本地 Agent 工作台。

  1. 1
    导入演示数据
    先让首页出现一组可浏览的任务和样例，后面的项目池、Deal 才有完整链路可看。
  2. 2
    在项目池录入第一条线索
    把项目名称、行业、负责人先放进项目池，先把线索进入系统。
  3. 3
    转成 Deal 并推进阶段
    把值得跟进的项目转成 Deal，体验阶段推进和待办记录。
  4. 4
    补齐 BP、初评或项目材料
    把审批会用到的材料挂到文档库，让 Deal 和 SOP 围绕同一份资料工作。
  5. 5
    发起审批或执行 SOP
    材料齐套后推进到审批，让系统承担流程提醒和决策沉淀。
🦐

配置第一只可用的本地 Agent

按这 5 步把模型、Gateway、Agent 和 Skills 串起来，确认你的本地 AI 能真正开始工作。

  1. 1
    环境体检
    确认 Node.js、OpenClaw CLI 和配置文件是否齐全，先把底座检查清楚。
  2. 2
    配置主模型
    添加至少一个主模型，确保后面创建 Agent 时有可用的推理能力。
  3. 3
    创建第一只 Agent
    创建第一只 Agent，给它独立身份、模型和工作区。
  4. 4
    喂技能或装灵魂
    确认可用 Skill，或去 AI 助手页导入灵魂配置让 Agent 更像你的团队。
  5. 5
    让 Agent 回复
    去实时聊天发第一条消息，确认 Agent 真正能对话。

Architecture

底层能力，留给需要确认的人看

Privix 是桌面级本地工作台：Rust 后端、SQLite 本地存储、OpenClaw 与 Hermes 双 Agent 引擎。

⚙

Tauri v2

Rust 后端 + 系统 WebView，安装包约 10MB，无需 Electron 运行时。跨平台支持 macOS、Windows、Linux。

⚡

Vanilla JS + Vite

零框架依赖。Vite 构建毫秒级热更新，原生 CSS 变量驱动主题系统。

🔒

SQLite · 数据主权

项目、会话与 Agent 配置全部存储在本机 SQLite 文件。无云端副本、无强制同步，删除后不可恢复。

🤖

双引擎: OpenClaw + Hermes

OpenClaw 负责多 Agent 编排与 MCP 工具链,Hermes 提供 SSE 流式对话与 Python 生态集成。23 家 LLM Provider 开箱即用,两种引擎按场景自由切换。

For Teams

给需要本地控制权的团队

当数据、密钥、Agent 配置和自动化流程都需要可控、可查、可复盘时，Privix 让团队先在本地把 AI 用起来。

01

数据零出境

会话、文档与研究内容全部存储在本地 SQLite。无云端上传、无强制同步、无云端副本，合规、法务与内审团队可直接审查。

02

API Key 零托管

模型凭据存储在操作系统钥匙串中。Privix 不进行中转或代理调用，也不持有任何密钥，可随时切换 Provider。

03

全流程可审计

Agent 调用与模型请求均在本地写入日志，数据库、配置与日志路径完全公开。

04

10 分钟部署

10MB 安装包，桌面级部署。IT 部门无需配置服务器、网关或容器集群，员工本地安装即可使用。

Enterprise · Coming Soon

Privix Enterprise — 面向组织的多租户版

当 HR / IT / 合规要统管全员 Agent 时,桌面版本地优势不再够用。Enterprise 版在桌面版之上加一层租户管理:中心化密钥、统一审计、成本配额、SSO 登录。

01

多租户 + SSO

组织-用户-角色三级数据隔离(Postgres RLS)。Keycloak OIDC 已集成,用户在企微 / 飞书 / Okta 登录后自动 JIT 建户并按 group 分配租户。

02

租户级密钥保险箱

管理员一次配置 OpenAI / Anthropic / Gemini / Azure / DeepSeek / Qwen / Ollama 密钥,全租户员工直接用。AES-256-GCM 加密落盘,plaintext 永不回读。

03

LLM 网关 + 配额

所有 completions 走服务端统一网关,流式 SSE 透传。按租户记录 tokens / 成本,月度 USD / 调用次数上限可设,到顶 429 强制拒绝。

04

集中审计 + 部署

登录 / 密钥轮换 / Agent 调用 / 配额修改全量审计,Postgres 可直接查询。Helm Chart + Docker Compose 一键起全栈(Postgres + Redis + Keycloak + 服务端 + admin 控制台)。
