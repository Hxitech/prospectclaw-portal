Why Local

资料留在你电脑上

Privix 把文档、会话、模型密钥和审计日志都留在本地。只有你主动调用模型时，才从本机直连自己配置的 Provider。

🔒

文件和会话留在本机

研究材料、项目记录、会话和 Agent 配置全部存储在本机 SQLite 文件中，没有强制同步和云端副本。

🔑

API Key 不交给 Privix

模型密钥加密存储在本地 keychain。Privix 不托管密钥、不代理请求，模型调用直接发往你配置的 Provider。

✈

无网也能查资料

不调用模型时，仍可浏览本地档案、编辑项目、维护 SOP 和整理知识库。网络只是模型调用所需，不是数据入口。

📄

关键动作可追踪

Agent 调用、模型请求和配置修改都写入本地日志，方便团队复盘、内审和问题定位。

Getting Started

先跑通一条真实工作流

如果你只是想知道 Privix 到底能干什么，先从本地 Agent 配置开始；行业模块可以之后再看。

📈

10 分钟体验 Invest 模块

从线索、公司资料到材料归档和审批，快速了解行业模块如何接入同一个本地 Agent 工作台。

  1. 1
    导入演示数据
    先让首页出现一组可浏览的任务和样例，后面的项目池、Deal 才有完整链路可看。
  2. 2
    在项目池录入第一条线索
    把项目名称、行业、负责人先放进项目池，先把线索进入系统。
  3. 3
    转成 Deal 并推进阶段
    把值得跟进的项目转成 Deal，体验阶段推进和待办记录。
  4. 4
    补齐 BP、初评或项目材料
    把审批会用到的材料挂到文档库，让 Deal 和 SOP 围绕同一份资料工作。
  5. 5
    发起审批或执行 SOP
    材料齐套后推进到审批，让系统帮你提醒流程、留下决策记录。
🦐

配置第一只可用的本地 Agent

按这 5 步把模型、Gateway、Agent 和 Skills 串起来，确认你的本地 AI 能真正开始工作。

  1. 1
    环境体检
    确认 Node.js、OpenClaw CLI 和配置文件是否齐全，先把底座检查清楚。
  2. 2
    配置主模型
    添加至少一个主模型，确保后面创建 Agent 时有可用的推理能力。
  3. 3
    创建第一只 Agent
    创建第一只 Agent，给它独立身份、模型和工作区。
  4. 4
    喂技能或装灵魂
    确认可用 Skill，或去 AI 助手页导入灵魂配置让 Agent 更像你的团队。
  5. 5
    让 Agent 回复
    去实时聊天发第一条消息，确认 Agent 真正能对话。

Architecture

底层能力，留给需要确认的人看

Rust 后端、SQLite 本地存储、OpenClaw 与 Hermes 双引擎。

⚙

Tauri v2

Rust 后端 + 系统 WebView，安装包 10MB，不依赖 Electron。macOS、Windows、Linux 都能跑。

⚡

Vanilla JS + Vite

不用前端框架。Vite 构建毫秒级热更新，主题系统跑在原生 CSS 变量上。

🔒

SQLite · 数据主权

项目、会话、Agent 配置都在本机 SQLite 文件里。没有云端副本，没有强制同步，删了就找不回。

🤖

双引擎: OpenClaw + Hermes

OpenClaw 跑多 Agent 编排和 MCP 工具链，Hermes 跑 SSE 流式对话和 Python 生态。23 家模型 Provider 装上就能用，两个引擎想用哪个用哪个。

For Teams

给需要本地控制权的团队

这些东西自己说了算的时候，Privix 让团队先在本地把 AI 用起来——数据、密钥、Agent 配置、自动化流程。

01

数据不出本机

会话、文档、研究内容都在本地 SQLite 文件里。没有云端上传、强制同步、云端副本，合规、法务、内审随时打开来看。

02

Key 你拿着

模型凭据存在你电脑的钥匙串里，Privix 不持有、不中转、不代理。想换 Provider，随时换。

03

动作有迹可循

Agent 调用、模型请求都在本地写日志。数据库、配置、日志路径完全公开。

04

装上就能用

10MB 安装包，跟普通软件一样装。IT 不用搭服务器、配网关、搞容器集群，员工自己装就行。

Enterprise · Coming Soon

Privix Enterprise — 面向组织的多租户版

桌面版适合个人和小团队。全公司一起用，HR 要管账号、IT 要管密钥、合规要看日志——这些都给 Enterprise 接管。

01

登录就是开账号

员工用企微、飞书、Okta 登录，账号自动建好、按部门进对应租户。IT 不用一个个开。底层是组织、用户、角色三层隔离，Postgres RLS 兜底。

02

密钥发一次

管理员配一次 OpenAI、Anthropic、Gemini、Azure、DeepSeek、Qwen、Ollama 的密钥，全公司直接用，员工不用自己申请 Key。密钥 AES-256-GCM 加密落盘，配进去就读不出来。

03

预算自动画线

每个团队花了多少 tokens、烧了多少钱实时看得到。月度上限设好，到点自动拦下来，不会月底打开账单吓一跳。底层是服务端网关接管所有模型请求，流式 SSE 透传。

04

可追溯，部署也快

谁登录、谁换密钥、谁调 Agent，全部留痕，SQL 直接查。部署用 Helm Chart 或 Docker Compose，一条命令把整套环境拉起来。
