Privacy First

隐私优先的架构设计

数据存储与密钥管理保留在本地，模型调用从本地直连用户配置的 Provider，不经 Privix 中转。

🔒

数据主权

项目、会话与 Agent 配置全部存储在本机 SQLite 文件中。无云端副本、无强制同步，卸载即清除全部数据。

🔑

API Key 不离机

模型密钥加密存储在本地 keychain。Privix 不进行中转或代理调用，请求直接发送至所配置的 Provider。

✈

离线可用

主要功能不依赖云端。无网络环境下仍可查阅档案、编辑项目、运行 SOP、浏览本地知识库，仅在调用模型时建立外部连接。

📄

可审计

所有操作均写入本地日志，数据库、配置与日志文件路径完全公开。合规、内审与法务团队可直接审查。

Getting Started

两条路径，快速上手

每一步说明操作目标、所在页面与完成标准。

📈

10 分钟跑通投资工作台

顺着这条链走，最快能把线索到审批的流程跑通。

  1. 1
    导入演示数据
    先让首页出现一组可浏览的任务和样例，后面的项目池、Deal 才有完整链路可看。
  2. 2
    在项目池录入第一条线索
    把项目名称、行业、负责人先放进项目池，先把线索进入系统。
  3. 3
    转成 Deal 并推进阶段
    把值得跟进的项目转成 Deal，体验阶段推进和待办记录。
  4. 4
    补齐 BP、初评或尽调材料
    把审批会用到的材料挂到文档库，让 Deal 和 SOP 围绕同一份资料工作。
  5. 5
    发起审批或执行 SOP
    材料齐套后推进到审批，让系统承担流程提醒和决策沉淀。
🦐

OpenClaw Agent 养成教程

按这 5 步把 OpenClaw 从「装好了」养到「第一只 Agent 真能用」。

  1. 1
    环境体检
    确认 Node.js、OpenClaw CLI 和配置文件是否齐全，先把底座检查清楚。
  2. 2
    给虾配脑子
    添加至少一个主模型，确保后面创建 Agent 时有可用的推理能力。
  3. 3
    开虾缸
    创建第一只 Agent，给它独立身份、模型和工作区。
  4. 4
    喂技能或装灵魂
    确认可用 Skill，或去 AI 助手页导入灵魂配置让 Agent 更像你的团队。
  5. 5
    让虾开口
    去实时聊天发第一条消息，确认 Agent 真正能对话。

Architecture

技术架构

Rust 后端、Vanilla JS 前端、SQLite 本地存储、OpenClaw 与 Hermes 双 Agent 引擎。

⚙

Tauri v2

Rust 后端 + 系统 WebView，安装包约 10MB，无需 Electron 运行时。跨平台支持 macOS、Windows、Linux。

⚡

Vanilla JS + Vite

零框架依赖。Vite 构建毫秒级热更新，原生 CSS 变量驱动主题系统。

🔒

SQLite · 数据主权

项目、会话与 Agent 配置全部存储在本机 SQLite 文件。无云端副本、无强制同步，删除后不可恢复。

🤖

双引擎: OpenClaw + Hermes

OpenClaw 负责多 Agent 编排与 MCP 工具链,Hermes 提供 SSE 流式对话与 Python 生态集成。23 家 LLM Provider 开箱即用,两种引擎按场景自由切换。
